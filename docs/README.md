# system-optimize documentation

* [steps.md](steps.md): each step of a run: what it reads, what it changes,
  what it records for `--undo`, and when it skips itself.
* [tools.md](tools.md): the helpers system-optimize reports and can install,
  how they relate, and the open-source projects that were considered and
  left out.

The [README](../README.md) covers installation, usage, undo, configuration,
logs and self-update; [CONTRIBUTING.md](../CONTRIBUTING.md) covers the code
layout and the tests.
